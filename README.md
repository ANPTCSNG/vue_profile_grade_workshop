
# Vue.js Mini Workshop — Personal Profile & Grade Calculator

A frontend mini workshop built with Vue.js 2 and Vuetify 2.

This project contains two interactive pages: a personal portfolio and a grade calculator.

## Features

### Personal Profile
- Personal information and educational background
- Hobbies and interests photo gallery
- Interactive image preview dialogs
- About Me and Contact popups
- Responsive Dark Coffee theme

### Grade Calculator
- Accepts integer scores from 0 to 100
- Calculates grades A, B, C, D, and F
- Validates invalid inputs
- Displays error alerts
- Supports resetting the form

## Grading Criteria

| Score | Grade |
|-------|-------|
| 80–100 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| 0–49 | F |

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd workshop
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run serve
```

Open:

http://localhost:8080/

## Production Build

```bash
npm run build
```

- `/` — Personal Profile
